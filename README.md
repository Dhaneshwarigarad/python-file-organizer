
# 🐍 Python File Organizer

A simple Python automation tool that automatically organizes files into separate folders based on their file types.

## 📌 About the Project

This is a personal Python project created to practice file handling and automation.

The program scans a selected folder and automatically moves files into categories such as:

- 📷 Images
- 📄 Documents
- 🎬 Videos
- 🎵 Music
- 📊 Excel
- 📁 Others

## 🛠️ Technologies Used

- Python
- OS Module
- Shutil Module

## ⚙️ How It Works

1. Enter the path of the folder you want to organize.
2. The program checks each file.
3. It identifies the file extension.
4. It creates the appropriate category folder.
5. It moves the file into that folder.

## ▶️ How to Run

Make sure Python is installed on your computer.

Run:


```bash
python file_organizer.py
